# 蒐集提示詞範本

把 `{縣市}` 換成目標縣市。先貼「共同規則」，再貼一段「分工」。

## 共同規則

```
你在為網站「土地使用計劃」蒐集資料，讀者是不懂土地法規的一般民眾。今天是 <今天日期>。

【收錄範圍】{縣市}境內，類型為：區段徵收、市地重劃（公辦）、市地重劃（自辦）、產業園區、科學園區、產業專用區、都市計畫整體開發。
只收「尚未完成」或「完成未滿 6 年」的案件。完成日取「工程完工、公共設施點交、土地分配公告期滿」三者最早的一項。
「構想／傳聞」也收，但必須有公開來源（政府、議會、媒體）。
不收：農地重劃、農村社區土地重劃、道路等公共工程的一般徵收、只變成公共設施而沒有產生產業／住宅／商業建地的案件、單一工廠擴廠（個案變更為零星工業區或乙種工業區）、單純通盤檢討、完成滿 6 年的案件。
同一計畫劃設多處整體開發區時，每一處拆成一筆；查不到逐區明細就不要編造，改在備註說明缺口。

【查資料】每一筆事實都必須來自你實際打開的網頁或 PDF 原文，搜尋摘要不能當證據。主要來源：{縣市}政府地政局、都市發展（計畫）局、經濟發展（產業）局、市（縣）議會、內政部國土管理署（中央都委會）、國科會科學園區管理局、經濟部產業園區管理局、主要媒體。

【寫法】
- 不推估或補數字；面積口徑不一時填最能代表範圍的官方數字並在 area_note 說明，不確定填 null。
- 不畫範圍、不推定地號、不列地主或權利人。
- summary：一到三句白話，說明在哪裡、要做什麼、現在到哪一步。
- stage 只能是：構想／傳聞、規劃中、審議中、已核定、施工中、已完成。
- 每個 source：title、url、publisher、kind（官方／議會／媒體）、date（來源發布日，可省略）、supports（支持哪些內容）。
- timeline 每筆：date（YYYY-MM-DD、YYYY-MM 或 YYYY）、event、source（sources 索引，從 0 開始）。
- uncertain：列出還沒查證清楚的事項。
- 輸出 JSON 陣列，欄位：name, county, districts, types, stage, area_ha, area_note, summary, timeline, completed_date, sources, uncertain。
```

## 分工（各段可分開做）
1. 區段徵收：地政局區段徵收開發區清單逐區檢查，並找規劃中、審議中的新案。
2. 公辦市地重劃：地政局公辦重劃區清單，判斷是否未完成或完成未滿 6 年，並找規劃中的新區。
3. 自辦市地重劃：地政局自辦重劃（籌備會、重劃會）清單逐區檢查。
4. 產業園區與科學園區：地方政府與經濟部的園區（報編中、開發中、近 6 年完成）、科學園區及其擴建。
5. 產業專用區、新訂或擴大都市計畫的整體開發區、以及只有政府／議會／媒體提過的開發構想。

## 複核

```
以下案件由別人蒐集，可能有錯。請逐案重新打開每個來源原文確認：來源存在且支持所寫內容；階段、日期、面積與原文一致；是否符合收錄範圍與 6 年規則。不支持的內容改正或刪除，打不開的來源刪除並記在 uncertain；刪完至少要剩一個有效來源，否則整案刪除並說明原因。回傳修正後的 JSON 陣列，另附刪除清單與原因。
```
