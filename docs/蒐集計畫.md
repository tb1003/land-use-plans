# 資料蒐集計畫（接續用）

## 已決定事項
- 收錄：區段徵收、市地重劃（公辦／自辦）、產業園區、科學園區、產業專用區、都市計畫整體開發；計畫中、審議中、施工中，或完成未滿 6 年。
- 「風聲」也收，但必須有公開來源（政府、議會、媒體），階段填「構想／傳聞」。
- 不收：農地重劃、道路等一般公共工程的一般徵收（除非屬於園區或大型開發的一部分）、單純通盤檢討。
- 順序：臺中市 → 臺北市、新北市、桃園市、臺南市、高雄市、新竹市、新竹縣 → 其他縣市。
- 地圖第一版只到縣市層級。
- 方式：多代理平行蒐集（每批 10 個代理以內），依類型分工，另有代理逐案開啟來源原文複核。

## 每批流程
1. 蒐集：依類型各派一個代理，列出候選案件與來源網址。
2. 合併：依案名與地點去重。
3. 複核：開啟每個來源原文，確認階段、日期、面積與 6 年規則；查不到原文的事項寫入 `uncertain`，不自行補數字。
4. 寫入 `data/cases/<縣市>.json`，執行 `npm run validate` 與 `npm run build`。

## 參考資料
