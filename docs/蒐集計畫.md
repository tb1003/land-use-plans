# 資料蒐集計畫（接續用）

## 已決定事項
- 收錄：區段徵收、市地重劃（公辦／自辦）、產業園區、科學園區、產業專用區、都市計畫整體開發；計畫中、審議中、施工中，或完成未滿 6 年。
- 「風聲」也收，但必須有公開來源（政府、議會、媒體），階段填「構想／傳聞」。
- 不收：農地重劃、道路等一般公共工程的一般徵收（除非屬於園區或大型開發的一部分）、單純通盤檢討。
- 順序：臺中市 → 臺北市、新北市、桃園市、臺南市、高雄市、新竹市、新竹縣 → 其他縣市。
- 地圖第一版只到縣市層級。
- 方式：多代理平行蒐集（每批 10 個代理以內），依類型分工，另有代理逐案開啟來源原文複核。

## 每批流程
1. 蒐集：依類型各派一個代理，列出候選案件與來源網址。
2. 合併：依案名與地點去重。
3. 複核：開啟每個來源原文，確認階段、日期、面積與 6 年規則；查不到原文的事項寫入 `uncertain`，不自行補數字。
4. 寫入 `data/cases/<縣市>.json`，執行 `npm run validate` 與 `npm run build`。

## 參考資料
- 一律重新從公開來源蒐集，不使用舊站「全台土地開發投資情報網」的 125 案做核對；舊站資料嚴格禁止修改。
- 臺中市第一批（2026-10-13）：5 個蒐集代理 → 1 個合併 → 4 個複核，共 39 案。
- 臺中市第二批（2026-10-13）：把「公共設施用地專案通盤檢討」65 處跨區市地重劃整體開發區拆成個別案件，8 個代理各負責一個專案，取得 62 處逐區資料；后里 1 處、豐潭雅神地區 2 處官方未公開逐區明細，尚未建檔。臺中市合計 100 案。

## 判斷慣例（第一批定下，後續縣市沿用）
- 「完成日」取工程完工、公共設施點交、土地分配公告期滿三者中最早發生的一項；早於 6 年門檻就不收。
- 單一工廠擴廠（個案變更為零星工業區、乙種工業區）不收。
- 只把土地徵收或變更為公共設施、沒有產生產業專區、住宅或商業等建地的案件不收。
- 由同一計畫劃設的多處整體開發區，拆成個別案件；官方查不到逐區明細時不自行編造，只記錄缺口。
- 本環境 WebFetch 無法使用；代理改用 curl 讀網頁、pdftotext 讀 PDF。
