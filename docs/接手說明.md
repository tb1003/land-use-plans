## 在 Mac mini 上開始
```bash
git clone -b claude/taiwan-land-acquisition-info-0h8dk9 https://github.com/tb1003/land-use-plans.git
cd land-use-plans
npm install
npm run dev        # 預覽，網址看終端機輸出
npm run validate   # 檢查資料
npm run build      # 檢查資料 + 型別 + 產生 dist/
```

## 每個縣市的做法
1. 打開 `docs/蒐集提示詞.md`，把 `{縣市}` 換成目標縣市，依「分工」逐段交給 Claude 蒐集（可以一次一段，或同時開多個對話）。
2. 每段結果是 JSON 陣列，格式同 `src/types.ts` 的 `LandCase`；`id` 用「縣市英文縮寫-案名雜湊」或任何不重複字串，`county` 填縣市全名，`checked_at` 填查核日。
3. 合併成 `data/cases/<縣市英文>.json`（例如 `hsinchu-city.json`），刪除重複的案子。
4. 再請 Claude 用「複核」段落逐案打開原文檢查一次。
5. 跑 `npm run build`，沒有錯誤就提交並推送。
