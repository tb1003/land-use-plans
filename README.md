# 土地使用計劃

讓一般民眾快速看懂全台「還沒完成、或完成未滿 6 年」的區段徵收、市地重劃、產業園區、科學園區、產業專用區與都市計畫整體開發案。

純靜態網站（Vite + React），不需要後端或資料庫。

## 在 Mac mini 上預覽

需要 Node.js 18 以上（`node -v` 確認）。

```bash
git clone https://github.com/tb1003/land-use-plans.git
cd land-use-plans
npm install
npm run dev
```

終端機會顯示網址（通常是 http://localhost:5173 ），用瀏覽器打開即可。同一個區網的手機也可以用終端機顯示的 `Network:` 網址開啟。

## 之後放到 NAS

```bash
npm run build      # 先檢查資料，再產生 dist/
```

把整個 `dist/` 資料夾放進 NAS 的網頁伺服器（例如 Synology Web Station 或 nginx 容器）任一目錄即可，不需要額外設定。

## 資料

- 每個縣市一個檔：`data/cases/<縣市英文>.json`，格式見 `src/types.ts`。
- `npm run validate` 會檢查欄位、列舉值、來源索引與日期；有錯誤就無法 build。
- 收錄規則：
  - 類型：區段徵收、市地重劃（公辦／自辦）、產業園區、科學園區、產業專用區、都市計畫整體開發。
  - 不收：農地重劃、一般公共工程（道路等）的一般徵收、單純通盤檢討。
  - 已完成的案件只保留完成未滿 6 年；網站依當天日期自動判斷，超過就不顯示。
  - 「構想／傳聞」也必須有公開來源（政府、議會或媒體），並在來源標示類別。
  - 每一筆時間軸事件都要對應一個來源；不確定的內容寫在 `uncertain`，不自行推估數字、不繪製範圍、不推定地號。
- 蒐集順序：臺中市 → 六都＋新竹市、新竹縣 → 其他縣市。
